# ClonerNews

A modern UI for the [HackerNews API](https://github.com/HackerNews/API), built with vanilla HTML, CSS and JavaScript.

## Features

- Browse stories, jobs and polls from HackerNews
- Lazy loading — posts load on demand, not all at once
- Live updates — new content is detected and shown every 5 seconds
- Comments displayed newest to oldest, linked to their parent post
- Throttling and debouncing to avoid unnecessary API requests

## How to run

Open `index.html` in your browser — no build tools or dependencies required.
